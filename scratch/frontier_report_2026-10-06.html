Solar Filament Segmentation Challenge 2026 · Status Report

現在地と次の計画

2026-10-06 時点の総括。定量面では我々の OOF refined PQ 0.443 が 公開されている誠実ティアの最高水準(0.423〜0.427)を上回る見込みで、 実質的に最前線。改善の次の一手は、エラー解剖で天井を測ってから選ぶ 「oracle駆動の機構選択」に移行した。まとめ: v64 learned component selector が次の実験。

1現在地 — 定量最前線の根拠

我々の確定構成(YOLO11m-seg 検出器 → MediSeg U-Net refiner → shrink → ownership)の fold2 OOF refined PQ は 0.4432。 これが「最前線」と言える根拠は3点:

  1. リーダーボードの上位は実力を反映していない。 0.55〜0.56 に並ぶ38チームのクラスタは、テスト180枚中77.2%が公開 MAGFiLO 1.0 とバイト一致する検証済みリーク由来(正解をそのまま提出)。 運営は「LBではなく定量70%+定性30%の合議制」と明言しており、 このクラスタは追走対象ではない。
  2. 誠実ティアの最前線は LB ~0.36・公開 val ~0.42。 最も詳細に開示している競合(too.foo)の公式プロトコル val は 0.423〜0.427、LB 0.36。我々の OOF 0.4432 は同一プロトコル (annotator×image基準のPQ)でこれを上回る。
  3. 実質天井は PQ 0.45〜0.55 と推定されている。 採点は annotator record 単位で、annotator 間一致率は Kappa 0.66。 全annotatorを同時に満たす単一予測集合は原理的に存在しないため、 0.44台は天井の帯に既に入っている。

注意(誠実な留保)

0.4432 は OOF(held-out fold)評価で LB への直接提出値ではない。 val protocol の差(我々 grouped 3fold / too.foo 独自holdout)はあるが、 同一の公式採点プロトコル基準の数字として比較可能。

§6.12 のレバーリスト(競合調査+未試行機構の棚卸し、優先度1〜7)は すべて paired 評価で消化した。採用0件だが、負の知見は確定的:

8連敗が教える構造的事実

「FNかFPの片方を改善する」単変数変更は、もう片方を悪化させて正味±0。 現構成の操作点近傍で PQ は局所的に平坦。有望なのは FN↔FP のトレードオフを「交換」ではなく「壊す」機構だけ — つまり両者を同時に下げるもの、または SQ(TP品質)だけを動かすもの。

FNの68%(729/1,071)は提案不在。つまり真のボトルネックは検出リコール — だが検出器側は全滅済み。verifier が強ければ conf floor を下げて 提案を増やしてもFPを制御できるため、selector は「FP除去」と 「リコール解放」の両側からトレードオフを壊せる唯一の機構となる。

6今後の計画

Phase B — v64 learned component selector(次の実行notebook)

solar_filament_v64_selector_fold2_colab.ipynb 生成済み。設計:

  • floor=0.05 の全提案を train-fold / val-fold 両方で収集し、 10特徴(conf/probmass/IoU/面積比/aspect/solidity/暗さコントラスト/ limb距離)を算出
